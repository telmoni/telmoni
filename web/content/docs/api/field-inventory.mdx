Telmoni keeps metadata about an agent's runs and drops everything else at the
door. This page is the whole list of what ingest reads from a span and from
its resource, and what becomes of each: the column it fills, the `attributes`
it is kept in under its own name, or the drop. **Any text, or array, under a
name this page does not list is dropped in every content mode**, the span kept
and the attribute named in the answer — content arrives under names no
convention gave it, so what is kept is this list, not a guess at what is
content.

The names are the [GenAI semantic conventions](https://github.com/open-telemetry/semantic-conventions-genai)'
at commit `6fd0d763a092db245a54104fc1124031eb3c51d2`, pinned on purpose: the
conventions have tagged no release and rename what Telmoni sums, so a rename
is a change to this page and to ingest, never to what is stored. What the
conventions do not name — runs, tags, bounds, sample rates — is Telmoni's own,
under `telmoni.*`; the user a span was for is `user.id`, from OpenTelemetry's
general registry.

The list is held to the code: a test in the server fails when ingest reads a
name this page lacks, or this page lists one ingest does not read. The console
shows the same list on a project's **Privacy** page, served from the same code.

## How to read it

- **On**: the spans the attribute belongs on, where Telmoni's SDKs and the
  conventions put it — every span of a run, the run itself (and the
  `telmoni.run.start` that opens it), a model call, a tool call, any span that
  carries it, or the resource every span of an export shares. Ingest reads it
  from whichever span carries it, a model's name or tokens on a step among
  them.
- **Kept as**: the column of `spans` it fills, `attributes` under its own
  name, or what the drop does with it.
- **Needs**: the project [content mode](/docs/api/ingest#what-is-dropped-at-the-door)
  it takes to keep it. Metadata is kept in every mode. Content would need `on`,
  or `sealed` for what Telmoni's SDK encrypted, but no project can be switched
  from `off` today, so content is dropped in every mode.
- **Rule**: its cap or format. A span whose field breaks its rule is refused
  whole; an attribute past its cap is dropped and the span kept. The
  resource's attributes are copied onto every span of its export, so they
  keep at most 2 KiB together, keys and values; one past that is dropped
  without a word.

Two things on the wire are not attributes: the instrumentation scope
`telmoni`, under which a span the conventions give no operation is a step
rather than a plain span, and the span named `telmoni.run.start`, which opens
a run and is never a row.

## Telmoni's own

| Attribute | On | Kept as | Needs | Rule |
|---|---|---|---|---|
| `telmoni.run_id` | every span | the column `run_id` | any | a UUID, the same on every span of a run; a span without it is refused |
| `telmoni.agent` | every span | the column `agent`, and a run's `name` where `gen_ai.agent.name` and `gen_ai.workflow.name` are unset | any | 1 to 128 characters; a span without it is refused |
| `user.id` | any span | the column `user_id`, as its HMAC-SHA-256 under a key of the project's own, the first 16 bytes in hex | any | 1 to 128 characters |
| `telmoni.tag.<key>` | any span | `tags`, under `<key>` | any | up to 32 tags; a key up to 64 characters, a value up to 256 |
| `telmoni.bound.stall_after_s` | the run | the column `bound_stall_after_s` | any | seconds, a whole number, 1 or more |
| `telmoni.bound.max_steps` | the run | the column `bound_max_steps` | any | a whole number, 1 or more |
| `telmoni.bound.max_cost_usd` | the run | the column `bound_max_cost_usd` | any | US dollars, above 0 |
| `telmoni.sample_rate` | the run | the column `sample_rate` | any | above 0, up to 1: the share of runs the SDK sends |
| `telmoni.cancelled` | any span | the column `status`, as `cancelled` | any | `true` on a span the agent cancelled |
| `telmoni.content` | any span | read and not kept: `sealed` would mark content the SDK encrypted, which no SDK does today and no project can keep | any | `sealed` |

The [coding-agent plugins](/docs/api/coding-agents) set one tag of their own:
`skills` on Claude Code's runs, the names of the skills the turn ran, joined by
commas. It is kept as any tag is.

## The conventions' fields

| Attribute | On | Kept as | Needs | Rule |
|---|---|---|---|---|
| `gen_ai.operation.name` | every span | the column `kind` | any | `invoke_agent` or `invoke_workflow` is the run; `chat`, `generate_content`, `text_completion` or `embeddings` a model call; `execute_tool` a tool call; any other span a step under the `telmoni` scope, a plain span elsewhere |
| `gen_ai.agent.name` | the run | the column `name` | any | 1 to 128 characters |

| `gen_ai.response.model` | a model call | the column `model` | any | 1 to 128 characters, as the provider spells it |
| `gen_ai.request.model` | a model call | the column `model`, where the response names none | any | 1 to 128 characters, as the provider spells it |

Each of these is kept in `attributes` under its own name, whatever its value's
type; a named array is kept as its JSON. A key is up to 128 characters and a
value up to 1,024, and a span keeps up to 64 attributes, its resource's among
them.

## Content

Content is what a person or a model wrote, and the people a span names. Each of
these is dropped at the door in every content mode, the span kept and the field
named in the answer, and nothing of it reaches a store: every project's mode is
`off`, and none can be switched to another today.

| Attribute | On | Kept as | Needs | Rule |
|---|---|---|---|---|
| `gen_ai.input.messages` | any span | dropped in every mode, the span kept | on, or sealed from Telmoni's SDK | content: what a person or a model wrote |
| `gen_ai.output.messages` | any span | dropped in every mode, the span kept | on, or sealed from Telmoni's SDK | content: what a person or a model wrote |
| `gen_ai.system_instructions` | any span | dropped in every mode, the span kept | on, or sealed from Telmoni's SDK | content: what a person or a model wrote |
| `gen_ai.tool.definitions` | any span | dropped in every mode, the span kept | on, or sealed from Telmoni's SDK | content: what a person or a model wrote |

## Everything else

| Attribute | On | Kept as | Needs | Rule |
|---|---|---|---|---|
| any other number or boolean | any span | `attributes`, under its own name, except a name under `telmoni.`, which is dropped as `unlisted` | any | a measurement no person writes; on the resource, dropped without a word |
| any other text or array | any span | dropped in every mode, the span kept and the attribute named in the answer as `unlisted` | any | content arrives under names no convention gave it; on the resource, dropped without a word |
| the span's events and status message | any span | never kept | any | where an exception writes its message and stack trace |
