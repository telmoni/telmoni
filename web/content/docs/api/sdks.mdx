---
title: "Client SDKs"
description: "The Telmoni SDKs for Python, TypeScript / JavaScript, Go and Rust: an agent's runs, steps, model calls and tool calls as OpenTelemetry spans, sent to Telmoni and nowhere else."
---

The SDKs record an agent's **runs**, and the **steps**, **model calls** and
**tool calls** inside each, as OpenTelemetry spans, and send them to
[ingest](/docs/api/ingest). Each one runs a tracer provider of its own beside
whatever OpenTelemetry your application already has, sends nothing outside a
run, and takes prompts, completions and tool payloads off every span before it
leaves the process unless you ask and the project's content mode allows.

| Language | Package | Requires | Source |
|---|---|---|---|
| **Python** | `telmoni` | Python 3.10 or later | [`sdk/python`](https://github.com/telmoni/telmoni/tree/main/sdk/python) |
| **TypeScript / JavaScript** | `telmoni` | Node.js 18.19 or 20.6 or later | [`sdk/typescript`](https://github.com/telmoni/telmoni/tree/main/sdk/typescript) |
| **Go** | `github.com/telmoni/telmoni/sdk/go` | Go 1.26 or later | [`sdk/go`](https://github.com/telmoni/telmoni/tree/main/sdk/go) |
| **Rust** | `telmoni-sdk` | Rust 1.98.1 or later | [`sdk/rust`](https://github.com/telmoni/telmoni/tree/main/sdk/rust) |

None is published to a package registry yet, so each installs from the
platform's repository, [`telmoni/telmoni`](https://github.com/telmoni/telmoni),
which holds them beside the ingest they send to; a `telmoni` package found on
npm, PyPI or crates.io is not Telmoni's. Each is built on its language's
OpenTelemetry SDK and sends with the language's own HTTP client, Rust with
reqwest. Python, TypeScript and Go carry nothing else; Rust also carries serde,
serde_json, tracing and uuid.

## A run

A run is one execution of an agent. Open one around the agent's work, and
inside it open a step for each unit of work, a model call around each call to
a model, and a tool call around each tool. The SDK sends the run's start at
once, so a run stalled in its first call is still heard, and the rest when
each span ends. Set `TELMONI_API_KEY` to a [project API key](/docs/api/api-keys)
holding the **ingest** scope.

<Tabs items={['Python', 'TypeScript', 'Go', 'Rust']}>
  <Tab value="Python">
    ```python
    from telmoni import Bounds, Telmoni, Usage

    telmoni = Telmoni.from_env()


    @telmoni.run("support-bot")
    def answer(question: str) -> str:
        with telmoni.step("plan"):
            with telmoni.model_call("gpt-4o-mini", provider="openai") as call:
                reply = ask_the_model(question)  # your provider's call
                call.answered(
                    response_model=reply.model,
                    usage=Usage(input_tokens=reply.usage.input, output_tokens=reply.usage.output),
                )
        with telmoni.tool_call("search"):
            results = search(reply.query)  # an exception marks the call failed
        return reply.text


    with telmoni.run(
        "support-bot",
        user_id="user_42",
        session_id="conv_7",
        tags={"env": "prod"},
        bounds=Bounds(stall_after_s=60, max_steps=10, max_cost_usd=1.5),
    ) as run:
        ...
    ```

    Each of `run`, `step`, `model_call` and `tool_call` is a context manager,
    an `async with`, and a decorator. An exception that escapes one marks the
    span failed with the exception's class, never its message, and is raised
    again; a `KeyboardInterrupt` or `asyncio.CancelledError` marks it
    cancelled. `fail("TimeoutError")` and `cancel()` do the same by hand.
    `run` raises `ValueError` for a blank agent name or a sample rate outside
    its range. A bound or a token count is read from a number or its text, a
    stall's, steps' or count's fraction cut, and of what Telmoni would refuse,
    these are left off with one warning: a bound outside 1 to 4294967295, a
    cost not above 0, a token count below 0 or past 64 bits, a tag whose key
    is not 1 to 64 characters or whose value is past 256, and the tags past
    the first 32 kept; an empty user, session, provider or response model is
    left off as unset. A name, model, provider, user, session, response model
    or error type that is no string goes as its text with one warning, as does
    a tag that is no string, finite number or bool; an exception or an
    exception's class handed to `fail()` goes as the class's name, never its
    message. Past Telmoni's caps, counted in characters, a name, the agent, a
    model, a provider, a response model or an error type is cut to its cap — a
    step's or a tool's name, and a model call's `<operation> <model>`, to 145,
    the rest to 128 — and a user past 128 or a session past 200 is left off,
    since cut it would name another; a step named nothing goes as `step`, and a
    model call with no model is named by its operation alone; each with one
    warning.
  </Tab>
  <Tab value="TypeScript">
    ```ts
    import { Telmoni, type Run } from 'telmoni';

    const telmoni = Telmoni.fromEnv();

    const text = await telmoni.run(
      'support-bot',
      { userId: 'user_42', sessionId: 'conv_7', tags: { env: 'prod' } },
      async (run) => {
        const reply = await run.step('plan', (step) =>
          step.modelCall('gpt-4o-mini', { provider: 'openai' }, async (call) => {
            const reply = await askTheModel(question); // your provider's call
            call.answered({
              responseModel: reply.model,
              usage: { inputTokens: reply.usage.input, outputTokens: reply.usage.output },
            });
            return reply;
          }),
        );
        await run.toolCall('search', {}, () => search(reply.query)); // a rejection marks it failed
        return reply.text;
      },
    );

    const answer = telmoni.wrap('support-bot', {}, async (question: string, run: Run) => '...');
    ```

    Each callback receives its handle and may be sync or async; the span ends
    when the callback settles. An error thrown inside marks the span failed
    with the error's class name and is thrown again; one named `AbortError`
    marks it cancelled. `fail('TimeoutError')` and `cancel()` do the same by
    hand, and `wrap` turns a function into one that opens a run per call.
    `run` throws a `TypeError` for a blank agent name and a `RangeError` for
    a sample rate that is no number or outside its range. A bound or a token
    count is read from a number, a bigint or a decimal numeral's text, a
    stall's, steps' or count's fraction cut, and of what Telmoni would refuse,
    these are left off with one warning: a bound outside 1 to 4294967295, a
    cost not above 0, a token count below 0 or past 64 bits, a tag whose key
    is not 1 to 64 characters or whose value is past 256, and the tags past
    the first 32 kept; an empty user, session, provider or response model is
    left off as unset. A name, model, provider, user, session, response model
    or error type that is no string goes as its text with one warning, as does
    a tag that is no string, finite number or boolean; an error, or a class,
    handed to `fail()` goes as its class's name, never its message. Past
    Telmoni's caps, counted in characters, a name, the agent, a model, a
    provider, a response model or an error type is cut to its cap — a step's
    or a tool's name, and a model call's `<operation> <model>`, to 145, the
    rest to 128 — and a user past 128 or a session past 200 is left off, since
    cut it would name another; a step named nothing goes as `step`, and a model
    call with no model is named by its operation alone; each with one warning.
  </Tab>
  <Tab value="Go">
    ```go
    client, err := telmoni.NewFromEnv()
    if err != nil {
    	log.Fatal(err)
    }
    defer client.Shutdown(context.Background())

    ctx, run := client.Run(ctx, "support-bot", telmoni.RunOptions{
    	UserID:    "user_42",
    	SessionID: "conv_7",
    	Tags:      map[string]string{"env": "prod"},
    	Bounds:    &telmoni.Bounds{StallAfterS: 60, MaxSteps: 10, MaxCostUSD: 1.5},
    })
    defer run.End()

    stepCtx, step := run.Step(ctx, "plan")
    _, call := run.ModelCall(stepCtx, "gpt-4o-mini", telmoni.ModelCallOptions{Provider: "openai"})
    reply, err := askTheModel(stepCtx, question) // your provider's call
    if err != nil {
    	call.Fail(err)
    } else {
    	call.Answered(telmoni.Answer{
    		ResponseModel: reply.Model,
    		Usage:         &telmoni.Usage{InputTokens: reply.Usage.Input, OutputTokens: reply.Usage.Output},
    	})
    }
    call.End()
    step.End()

    _, tool := run.ToolCall(ctx, "search", telmoni.ToolCallOptions{})
    if _, err := search(reply.Query); err != nil {
    	tool.Fail(err)
    }
    tool.End()
    ```

    Each opener returns a context carrying its span, so your own OpenTelemetry
    spans started with it nest under the run, and the handle to end with
    `defer`; `telmoni.RunFromContext(ctx)` finds the run deep in a call stack.
    `Fail(err)` marks the span failed with the error's Go type, never its
    message, and marks it cancelled for `context.Canceled`;
    `FailWith("TimeoutError")` and `Cancel()` do the same by hand. The SDK
    never panics: a `Client` not from `New`, the nil a failed `New` returns
    among them, sends nothing; a blank agent name opens a run that does
    nothing, and of what Telmoni would refuse, these are left off with one
    warning — a `StallAfterS` or `MaxSteps` past 4294967295 or below 0, a
    `MaxCostUSD` that is no finite number above 0 (0 leaves any of the three
    unset), a token count below 0, a tag whose key is not 1 to 64 characters
    or whose value is past 256, and the tags past the first 32 kept, by key.
    Past Telmoni's caps, counted in characters, a name, the agent, a model, a
    provider, a response model or an error type is cut to its cap — a step's
    or a tool's name, and a model call's `<operation> <model>`, to 145, the
    rest to 128 — and a user past 128 or a session past 200 is left off,
    since cut it would name another; a step named nothing goes as `step`, and
    a model call with no model is named by its operation alone; each with one
    warning.
  </Tab>
  <Tab value="Rust">
    ```rust
    use telmoni_sdk::{Bounds, Config, ModelCallOptions, Reply, RunOptions, Telmoni, ToolCallOptions, Usage};

    let telmoni = Telmoni::new(Config::from_env());

    let run = telmoni.run(
        "support-bot",
        RunOptions {
            user_id: Some("user_42".into()),
            session_id: Some("conv_7".into()),
            tags: [("env".to_owned(), "prod".to_owned())].into(),
            bounds: Bounds { stall_after_s: Some(60), max_steps: Some(10), max_cost_usd: Some(1.5) },
            ..RunOptions::default()
        },
    )?;
    let reply = {
        let step = run.step("plan");
        let call = step.model_call("gpt-4o-mini", ModelCallOptions { provider: Some("openai".into()), ..ModelCallOptions::default() });
        let reply = ask_the_model(question)?; // your provider's call
        call.answered(Reply {
            response_model: Some(reply.model.clone()),
            usage: Some(Usage { input_tokens: Some(reply.usage.input), output_tokens: Some(reply.usage.output), ..Usage::default() }),
            ..Reply::default()
        });
        reply
    };
    let tool = run.tool_call("search", ToolCallOptions::default());
    if search(&reply.query).is_err() {
        tool.fail("TimeoutError");
    }
    drop(tool);
    run.end();
    telmoni.shutdown();
    ```

    Each handle is a guard that ends its span when dropped or on `end()`.
    `run` returns an error for a blank agent name or a sample rate outside
    its range, and `record_run` for the cases
    [below](#a-run-recorded-after-it-ended); nothing else in the SDK fails:
    of what Telmoni would refuse, these are left off with one warning — a
    `stall_after_s` or `max_steps` that is no whole number from 1 to
    4294967295, a `max_cost_usd` that is no finite number above 0, a token
    count below 0, a tag whose key is not 1 to 64 characters or whose value
    is past 256, and the tags past the first 32 kept, by key — and an export
    that fails is warned about, never returned. Past Telmoni's caps, counted
    in characters, a name, the agent, a model, a provider, a response model or
    an error type is cut to its cap — a step's or a tool's name, and a model
    call's `<operation> <model>`, to 145, the rest to 128 — and a user past
    128 or a session past 200 is left off, since cut it would name another; a
    step named nothing goes as `step`, and a model call with no model is named
    by its operation alone; each with one warning. The closure forms `run_with`, `step_with`, `model_call_with` and
    `tool_call_with` end the span when the closure returns, and their `try_`
    forms mark an `Err` on the span with the error's type name before
    returning it unchanged. `fail("TimeoutError")` and `cancel()` do the same
    by hand, and `context()` or `attach()` make the run current for your own
    spans.
  </Tab>
</Tabs>

Flush before a short-lived process exits (`flush()` / `flush()` / `Flush(ctx)`
/ `flush()`), or shut the client down, which flushes first; a long-lived one
needs neither.

## A run recorded after it ended

A job that keeps its own log, or a hook that runs once the work it reports is
over, hands the finished run over whole, as data: its id, a UUID you give and
keep with the log; its agent, user, session and tags; its start and end and
how it ended; and its steps and calls, each with its own times. A step holds
the calls made inside it. A record the export queue has no room for is refused
whole, before anything is queued: flush, or wait, and record it again. Its
times are read as the clock of the process that sends it: where that clock is
a time zone or a date out, [ingest moves the record](/docs/api/ingest#what-is-kept)
by as much, so time a record by the clock that sends it.

<Tabs items={['Python', 'TypeScript', 'Go', 'Rust']}>
  <Tab value="Python">
    ```python
    from datetime import datetime, timezone

    from telmoni import ModelCallRecord, RunRecord, ToolCallRecord, Usage

    at = lambda s: datetime(2026, 10, 12, 9, 0, s, tzinfo=timezone.utc)

    telmoni.record_run(
        RunRecord(
            run_id="3d6f8a1c-5b2e-4f7a-9c0d-8e1f2a3b4c5d",
            agent="nightly-triage",
            session_id="conv_7",
            start=at(0),
            end=at(9),
            inside=[
                ModelCallRecord(
                    model="gpt-4o-mini", provider="openai", start=at(0), end=at(2),
                    usage=Usage(input_tokens=1200, output_tokens=85),
                ),
                ToolCallRecord(name="search", start=at(2), end=at(3), error_type="TimeoutError"),
            ],
        )
    )
    telmoni.flush()
    ```

    Times carry their timezone. A blank agent, a run id that is neither a
    hyphenated UUID nor 32 hex digits, or is the nil UUID, a time without its
    timezone or outside what Telmoni reads (after the Unix epoch, and less than
    2^64 nanoseconds after it, in July 2554), an empty step's name or model,
    text longer than Telmoni keeps (a step's or a tool's name past 145
    characters, the agent, a model, a provider, a user or an error type past
    128, a session past 200, or a model call's operation and model past 144
    together), or a span that ends before it starts raises `ValueError`. A field of the wrong type raises
    `TypeError` — a time that is no `datetime`, an item of another class,
    `inside` or `calls` that is no sequence (a list or a tuple) — save a token
    count, read as a whole number where it can be and else left off with one
    warning, and an `operation` of `None`, a chat. Either way, nothing is sent.
  </Tab>
  <Tab value="TypeScript">
    ```ts
    telmoni.recordRun({
      runId: '3d6f8a1c-5b2e-4f7a-9c0d-8e1f2a3b4c5d',
      agent: 'nightly-triage',
      sessionId: 'conv_7',
      start: new Date('2026-10-12T09:00:00Z'),
      end: new Date('2026-10-12T09:00:09Z'),
      inside: [
        {
          type: 'model_call',
          model: 'gpt-4o-mini',
          provider: 'openai',
          start: new Date('2026-10-12T09:00:00Z'),
          end: new Date('2026-10-12T09:00:02Z'),
          usage: { inputTokens: 1200, outputTokens: 85 },
        },
        {
          type: 'tool_call',
          name: 'search',
          start: new Date('2026-10-12T09:00:02Z'),
          end: new Date('2026-10-12T09:00:03Z'),
          errorType: 'TimeoutError',
        },
      ],
    });
    await telmoni.flush();
    ```

    A time is a `Date` or milliseconds since the Unix epoch; a step is
    `{ type: 'step', name, start, end, calls }`. A blank agent, a run id that
    is neither a hyphenated UUID nor 32 hex digits, or is the nil UUID, or an
    empty step's name or model throws a `TypeError`, as does a field of the
    wrong type — a time that is not one, an item of no known `type`, `inside`
    or `calls` that is no array, tags or a usage that is no object — save a
    token count, read as a whole number where it can be and else left off with
    one warning. A time outside what Telmoni reads (after the Unix epoch, and
    less than 2^64 nanoseconds after it, in July 2554), text longer than
    Telmoni keeps (a step's or a tool's name past 145 characters, the agent, a
    model, a provider, a user or an error type past 128, a session past 200,
    or a model call's operation and model past 144 together, counted in
    characters), or a span that ends before it starts throws a `RangeError`. Either way, nothing is sent.
  </Tab>
  <Tab value="Go">
    ```go
    start := time.Date(2026, 10, 12, 9, 0, 0, 0, time.UTC)
    err := client.RecordRun(ctx, telmoni.RunRecord{
        RunID:     "3d6f8a1c-5b2e-4f7a-9c0d-8e1f2a3b4c5d",
        Agent:     "nightly-triage",
        SessionID: "conv_7",
        Start:     start,
        End:       start.Add(9 * time.Second),
        Inside: []telmoni.RecordItem{
            telmoni.ModelCallRecord{
                Model: "gpt-4o-mini", Provider: "openai",
                Start: start, End: start.Add(2 * time.Second),
                Usage: &telmoni.Usage{InputTokens: 1200, OutputTokens: 85},
            },
            telmoni.ToolCallRecord{
                Name: "search", ErrorType: "TimeoutError",
                Start: start.Add(2 * time.Second), End: start.Add(3 * time.Second),
            },
        },
    })
    client.Flush(ctx)
    ```

    A step is a `telmoni.StepRecord` with its `Calls`. A blank agent, a run
    id that is not a UUID or is the nil UUID, a time that is zero or outside
    what Telmoni reads (after the Unix epoch, and less than 2^64 nanoseconds
    after it, in July 2554), an empty step's name or model, text longer than
    Telmoni keeps (a step's or a tool's name past 145 characters, the agent, a
    model, a provider, a user or an error type past 128, a session past 200,
    or a model call's operation and model past 144 together), a nil item or a
    span that ends before it starts returns an error, and nothing is sent.
  </Tab>
  <Tab value="Rust">
    ```rust
    use std::time::{Duration, SystemTime};

    use telmoni_sdk::{ModelCallRecord, RunRecord, ToolCallRecord, Usage};

    // 2026-10-12T09:00:00Z, and what came after it.
    let start = SystemTime::UNIX_EPOCH + Duration::from_secs(1_791_795_600);
    let at = |millis| start + Duration::from_millis(millis);

    telmoni.record_run(RunRecord {
        session_id: Some("conv_7".into()),
        inside: vec![
            ModelCallRecord {
                provider: Some("openai".into()),
                usage: Some(Usage { input_tokens: Some(1200), output_tokens: Some(85), ..Usage::default() }),
                ..ModelCallRecord::new("gpt-4o-mini", start, at(2_000))
            }
            .into(),
            ToolCallRecord {
                error_type: Some("TimeoutError".into()),
                ..ToolCallRecord::new("search", at(2_000), at(3_000))
            }
            .into(),
        ],
        ..RunRecord::new("3d6f8a1c-5b2e-4f7a-9c0d-8e1f2a3b4c5d", "nightly-triage", start, at(9_000))
    })?;
    telmoni.flush();
    ```

    A step is a `StepRecord` with its `calls`. A blank agent
    (`Error::EmptyAgent`), a run id that is not a UUID or is the nil UUID
    (`Error::RunId`), an empty step's name or model (`Error::EmptyName`), a
    time outside what Telmoni reads, after the Unix epoch and less than 2^64
    nanoseconds after it, in July 2554 (`Error::RecordedTime`), text longer
    than Telmoni keeps — a step's or a tool's name past 145 characters, the
    agent, a model, a provider, a user or an error type past 128, a session
    past 200, or a model call's operation and model past 144 together
    (`Error::TooLong`) — a span that
    ends before it starts (`Error::EndBeforeStart`) or a configured sample
    rate outside its range (`Error::SampleRate`) is returned as an error, and
    nothing is sent.
  </Tab>
</Tabs>

The run is sent as the live calls would have sent it, through the same
exporter, content rules and sample rate, in a trace of its own named by the
run's id, whatever trace is current. Each span's id is derived from the run's
id and the span's place in the record, and a record travels in bodies of its
own, so the same record sent again is the same bytes, whatever else the client
is sending, which Telmoni answers within the hour as it answered the first,
storing nothing twice: give a run the same id each time you send it. A record
holds no content.
The [coding-agent plugins](/docs/api/coding-agents) are built on it.

## A run across services

An agent whose work spans more than one service — an orchestrator handing a
task to a worker, a tool served over HTTP — is still one run. Before the
request leaves, `inject` writes into its headers the W3C `traceparent` of the
span current inside the run and the run's id and agent as the W3C `baggage`
members `telmoni.run_id` and `telmoni.agent`, beside whatever members the
headers hold already. In the service that answers, `extract` reads them back
as the run continued there: the steps and calls it opens carry the caller's
run and take the caller's span as their parent, so the trace shows the work
where it was asked for, and the trace list shows one run, not one a service.

<Tabs items={['Python', 'TypeScript', 'Go', 'Rust']}>
  <Tab value="Python">
    ```python
    # The orchestrator, inside a run.
    with telmoni.step("delegate"):
        headers = {"Content-Type": "application/json"}
        telmoni.inject(headers)
        requests.post("https://worker.internal/work", json=task, headers=headers)

    # The worker.
    @app.post("/work")
    def work(request):
        run = telmoni.extract(request.headers)
        with telmoni.step("work", run=run):
            ...
    ```
  </Tab>
  <Tab value="TypeScript">
    ```ts
    // The orchestrator, inside a run.
    await run.step('delegate', async (step) => {
      const headers = new Headers({ 'content-type': 'application/json' });
      telmoni.inject(headers, step);
      await fetch('https://worker.internal/work', { method: 'POST', headers, body });
    });

    // The worker.
    app.post('/work', async (req, res) => {
      const run = telmoni.extract(req.headers);
      await run?.step('work', async (step) => { /* ... */ });
    });
    ```
  </Tab>

    ```rust
    // The worker.
    let headers: HashMap<String, String> = request.headers_as_map();
    if let Some(run) = telmoni.extract(&headers) {
        let step = run.step("work");
        // ...
    }
    ```

    `inject` and `extract` take any `Carrier`: a type that is both an
    OpenTelemetry `Injector` and `Extractor`, as `HashMap<String, String>`
    is; wrap a request's own headers in one.
  </Tab>
</Tabs>

In TypeScript, `inject` takes the handle to write from, or writes from the
active context where your application runs OpenTelemetry's context manager;
in Rust, `inject` reads the current context, which a handle's `attach()` or
`FutureExt::with_context` sets, and `inject_from` takes a handle's `context()`.
The worker never ends a run it continued: the orchestrator's own span does,
and until it arrives the run is open with what the worker sent. Headers that
name no run — no `traceparent`, no `telmoni.run_id`, a malformed one —
continue nothing, and a step opened then is outside a run and sends nothing.
A run sampled out hands nothing on, so no half of it reaches Telmoni. The
headers carry the run's id and agent and nothing else; a service sending
under another project's key records the spans as that project's own run, so a
forged header reaches no other tenant. Telmoni's own helpers write and read
the headers; no propagator is set globally, since your application's
propagators are its own.

## What a run sends

A run is a span of its own, named `invoke_agent <agent>`, inside your current
trace when one is current and a trace of its own otherwise. It carries the
run's id (`telmoni.run_id`, a UUID), its agent (`telmoni.agent`), the user
and conversation you named (`user.id`, `gen_ai.conversation.id`), the first 32
of its tags Telmoni would keep, the most it keeps, as `telmoni.tag.<key>`, the
bounds and the sample rate; a `telmoni.run.start`
span of no duration goes out at once under it. Every span inside the run
carries the run's id, agent, user and session, so Telmoni knows each
span's run without waiting
for the trace's tree. The resource every span of an export shares names the
SDK (`telemetry.distro.name` `telmoni`, its version, and the OpenTelemetry
SDK's name, language and version) and, where you set them, the deployment:
`deployment.environment.name` from the `environment` option or
`TELMONI_ENVIRONMENT` (`production`, `staging`), and `service.version` from
`release` or `TELMONI_RELEASE` (a version or a commit), which Telmoni keeps as
the `environment` and `release` of every span and the trace list
[filters](/docs/workspace/traces#filters) by. A step is a span named as you named it; a model call is
`chat <model>` (or the operation you gave) with the model asked for, the
model that answered, the provider and the token counts under the GenAI
conventions' names, each a whole number from 0, another left off the call
with one warning; a tool call is `execute_tool <name>`. The exception's class
alone marks a failure, as `error.type`; no message, stack trace or event is
ever sent. The [ingest page](/docs/api/ingest) lists every attribute and what
the server keeps of each.

### Content

Prompts, completions, tool arguments and results — `input_messages`,
`output_messages`, `system_instructions`, `arguments`, `returned(...)` — are
recorded on the span and taken off by the exporter before anything leaves
the process. They are sent only when the client is built with
`capture_content` on **and** the project's content mode, which the SDK learns
from the server's first answer, is `on`. No project can be switched to `on`
today, so content never leaves the process. The server's own drop at the door
is the second lock, not the first.

### Sampling

`sample_rate`, on the client or on one run, is the share of runs sent, a
number above 0 and up to 1. A run sampled out is dropped whole in the SDK,
its start among it, never through the trace's sampled flag, so your
application's own sampling is untouched and the volume Telmoni sees is a
dial you hold. A step or call still open when its run ends is dropped too,
however late it ends.

### Beside your own OpenTelemetry

The SDK builds every part of its tracer provider itself — resource, sampler,
limits, batching — so none of your `OTEL_*` variables reaches it, and it
neither replaces your provider nor sends your spans to Telmoni. A run joins
the trace that is current where it begins, and your spans opened inside it
nest under the run. The run's sampled flag follows the trace it joins; a run
that starts a trace of its own takes the decision your own sampler gives it —
given as the `sampler` option in every SDK, Python falling back to your
provider's sampler when you give none — so your application keeps its own sampling rate inside runs as
outside them. A run inside a trace your application does not sample is still
sent.

### Answers and warnings

The SDK batches spans and sends them in the background, on a bounded queue,
so a slow Telmoni never slows an agent. Each request times out after 10
seconds. It retries a `429` or a `503` after its `Retry-After`, waiting at most
60 seconds, and a request that failed or timed out before its answer's status
after 1 second, then 2; after three attempts in all it drops the batch with one
warning. Any other refusal is logged once and never retried, and an answer whose
body breaks after its status, or runs past the 10 seconds, is decided by its
status, read as far as it came. Each attempt carries `Telmoni-Sent-At`, the
agent's clock as it leaves, so [ingest](/docs/api/ingest#what-is-kept) can move
a run from a clock a time zone or a date out as one. A flush waits up to 30 seconds. An attribute the
server drops is logged once: content with the project's content mode, which
decides the drop, and a link to [what is dropped at the
door](/docs/api/ingest#what-is-dropped-at-the-door); text the field inventory
does not name with the `telmoni.tag.<key>` that would keep it.

### The key on the wire

The key travels as a bearer over HTTPS. Plain HTTP is accepted only to this
machine, for a server you run beside the agent: `localhost`, a name under it,
an address in `127.0.0.0/8`, or `::1`, an IPv4-mapped address such as
`[::ffff:127.0.0.1]` counting as its IPv4. Python, TypeScript and Go refuse any
other `http://` endpoint when the client is built, and Rust when the first
export would go, with one warning. An endpoint given without a scheme gets
`https://`, or `http://` for this machine, as the CLI reads one; any scheme
but those two is refused the same way, as is an endpoint the four SDKs could
read two ways: one that is not printable ASCII once the whitespace around it
is trimmed, or holds credentials, a percent-escape, a query, a fragment, a `.`
or `..` segment or a character a URL parser would escape, such as a space or
`|`, or a port of 0 or past 65535, or whose host is neither a name of letters,
digits, dots, hyphens and underscores, in labels of 1 to 63 characters with no
hyphen at either end and the last no number, nor an IPv4 address in four
decimal parts, nor an IPv6 address in brackets. Write an
address in full, `127.0.0.1` rather than `127.1`, and a name in another script
in its `xn--` form. No SDK follows a redirect, which could carry the key to
another host, and the key never appears in a log, a warning or an error.

`environment` and `release` name the deployment every span is sent from, as
the resource's `deployment.environment.name` and `service.version`; a blank
one is unset, and nothing is sent for one unset.

Each SDK keeps the API key out of the configuration's printed form: Rust's
`Debug` shows `<redacted>` in its place and serialization skips it; Python
holds it as a `Secret` that `repr`, `str` and `dataclasses.asdict` show
redacted; Go's `String` and `GoString` redact it and JSON skips it;
TypeScript holds `apiKey` as a non-enumerable property, which `console.log`
and `JSON.stringify` pass over.

## Environment variables

`from_env` / `fromEnv` / `NewFromEnv` / `Config::from_env` read:

| Variable | Description | Default |
|---|---|---|
| `TELMONI_ENDPOINT` | The origin ingest is served on: Telmoni's machine host, or your own deployment's | `https://api.telmoni.com` when unset or blank |
| `TELMONI_API_KEY` | An [API key](/docs/api/api-keys) holding the **ingest** scope, created on a project's API keys page | None |
| `TELMONI_ORG` | The organization's ID (`org_...`), held and not sent: the key names the project | None |
| `TELMONI_ENVIRONMENT` | The deployment this process runs in — `production`, `staging` — sent as `deployment.environment.name` | None: nothing is sent |
| `TELMONI_RELEASE` | The release this process runs — a version or a commit — sent as `service.version` | None: nothing is sent |

Every SDK reads these five and no others. OpenTelemetry's own `OTEL_*`
variables are your application's, for its own exporters, and change nothing
of the SDK's: `OTEL_RESOURCE_ATTRIBUTES` in particular reaches nothing the
SDK sends.
