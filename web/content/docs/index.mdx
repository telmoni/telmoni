Telmoni is privacy-first, open-source monitoring for AI agents. Know when your
agents fail, stall, loop or overspend, and stop them at the cap you set.
Prompts stay in your process unless you turn content on. Its SDKs record an agent's runs, ingest keeps them as metadata with content dropped at
the door, or kept in full where a project turns it on
([Content](/docs/monitoring/content)), and the console reads them as [traces](/docs/monitoring/traces),
grouped by session or user where you ask, [alerts](/docs/monitoring/alerts) on them,
and [dashboards](/docs/monitoring/dashboards) of their spend.
Underneath is a foundation for organizations and their projects: members and
roles, API keys, notifications and a hash-chained audit log, with a CLI and an
HTTP API. These documentation pages describe the open-source
platform, hosted cloud service, console interface, developer tools, and HTTP
API as implemented today. Telmoni has not launched and is not at 1.0: until
then it changes every month, sometimes incompatibly.

## Platform capabilities

Telmoni runs as an open-source platform deployed on your own infrastructure,
and, from launch, as a hosted cloud service:

- **[Hosted cloud service](https://telmoni.com)**: Run for you on Google Cloud,
  with sign-in through an identity provider and the free
  [Hobby plan](https://telmoni.com/plans).
- **[Self-hosted deployment](/docs/self-host/overview)**: Run the complete platform
  on your own infrastructure using [Docker Compose](/docs/self-host/docker-compose) or
  the [Kubernetes Helm chart](/docs/self-host/kubernetes), backed by PostgreSQL 17
  with `pgvector`, ClickHouse and Redis 7.
- **[Organizations and projects](/docs/workspace/organizations-and-projects)**: Two
  tiers. An organization holds projects, its own settings and a rolled-up audit
  log; a project holds API keys and notification connectors.
- **[Members and roles](/docs/workspace/roles)**: Role-based access control with
  three roles, **Owner**, **Admin**, and **Member**, governing both
  organization administration and project resources.
- **[Audit log](/docs/workspace/audit-log)**: Append-only audit logging linking
  each recorded event into a SHA-256 hash chain, verified every 24 hours by a
  background sweep.
- **[Notifications and connectors](/docs/integrations/notifications)**: Project
  and organization notices, and fan-out delivery to
  [Slack](/docs/integrations/slack) and signed
  [Webhooks](/docs/integrations/webhooks).
- **[Alerts](/docs/monitoring/alerts)**: A measure of a project's runs, steps,
  model calls, tool calls or retrievals over the last hour, day or week, or their spend
  over the month as a budget, against an alert threshold and an optional
  warning one, evaluated every minute; each incident
  told to the feed and the connectors an alert links, and acknowledged or
  resolved in the console.
- **[AI Context Agent](/docs/self-host/agent)**: Embedded context assistant that,
  where the deployment configures a model, answers questions about a project's
  activity, members, connectors, and audit log in the console (`⌘J`), with
  numbered citations.
- **[Telmoni CLI](/docs/api/cli)**: The official command-line interface with interactive
  device code authorization ([RFC 8628](https://www.rfc-editor.org/rfc/rfc8628)),
  organization switching, and JSON output from `telmoni status --json`.
- **[Client SDKs](/docs/api/sdks)**: SDKs for Python, TypeScript / JavaScript, Go and
  Rust that record an agent's runs, steps, model calls, tool calls and retrievals as
  OpenTelemetry spans, with content taken off before it leaves the process
  unless you turn it on and the project keeps content,
  and hold a run to the caps on its steps and spend you give it, in the
  agent's own process; each installed with its language's own tool.
- **[Frameworks](/docs/api/frameworks)**: The OpenAI and Anthropic SDKs,
  LangChain and LangGraph, the OpenAI Agents SDK, CrewAI, LiteLLM and the
  Vercel AI SDK, reporting their runs through their own OpenTelemetry
  instrumentation, with no SDK of ours.
- **[Coding agents](/docs/api/coding-agents)**: Each turn of Claude Code, Codex or
  Antigravity recorded as a run by its plugin, with no code: metadata alone, unless you
  turn its content on.
- **[API keys and /v1 API](/docs/api/api-keys)**: Project-owned `tm_` keys,
  each opening [ingest](/docs/api/ingest), the read-only [API](/docs/api/reference)
  or both, with a 24-hour grace period on rotation.

## Where to start

   the organization your first sign-in creates, and your first project.
2. [Telmoni CLI](/docs/api/cli): Installing the CLI and signing in via device code or API key.
3. [Client SDKs](/docs/api/sdks): Recording an agent's runs from Python, TypeScript, Go or Rust.
